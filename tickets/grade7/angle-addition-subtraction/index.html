כיתה ז׳ · קבוצה הטרוגנית · 3–5 דקות

כרטיס כניסה: חיבור וחיסור זוויות

שימו לב: בסימון שלוש אותיות, האות האמצעית היא קודקוד הזווית.

1 · כניסה
נתון: ∠ABD = 40° ו־∠DBC = 60°.
חשבו את ∠ABC.
הקרן BD נמצאת בתוך הזווית ABC. איזו פעולה מחברת את שני החלקים?
פתרון: ∠ABC = ∠ABD + ∠DBC = 40° + 60° = 100°.
2 · יישום
הנקודות A,B,C נמצאות על ישר אחד. ∠ABD = 120°.
כתבו בשלוש אותיות את הזווית המתקבלת מן החיסור ∠ABC − ∠ABD.
הזווית ABC היא זווית שטוחה. אחרי שמסירים ממנה את ABD, אילו שתי קרניים נשארות?
פתרון: ∠ABC − ∠ABD = ∠DBC (וגם ∠CBD הוא אותו שם זווית). גודלה 60°.
3 · חשיבה
נתון: ∠ABD = 55°, ∠DBC = 35°.
כתבו בשלוש אותיות את הזווית המתקבלת מן החיבור ∠ABD + ∠DBC.
בחיבור זוויות סמוכות, הקרן המשותפת נעלמת משם הזווית הכוללת. חפשו את שתי הקרניים החיצוניות.
פתרון: ∠ABD + ∠DBC = ∠ABC. גודלה 55°+35°=90°.
